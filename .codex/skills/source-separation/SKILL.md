# Source Separation

This skill is mainly for future Phase 2 and Phase 3 work.

## Core rules

- Do not install or use heavy separation extras unless the current row requires them.
- Keep broad stems limited to the spec-defined categories.
- Route follow-on analyzers by source type.
- Record artifact provenance and privacy-sensitive storage behavior.
